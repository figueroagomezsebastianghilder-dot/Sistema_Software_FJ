# Sistema Integral Software FJ

## Descripción
Aplicación desarrollada en Python para gestionar clientes, servicios y reservas de la empresa ficticia Software FJ.

## Funcionalidades
- Registro y consulta de clientes.
- Gestión de reservas de salas.
- Alquiler de equipos tecnológicos.
- Administración de asesorías especializadas.
- Confirmación y cancelación de reservas.
- Validación de datos.
- Manejo de excepciones personalizadas.
- Registro de eventos y errores mediante archivos logs.

## Tecnologías utilizadas
- Python.
- Visual Studio Code.
- Programación orientada a objetos.
- GitHub.

## Ejecución
Para iniciar la aplicación, ejecutar:

`python main.py`

Para ejecutar las pruebas:

`python main_pruebas.py`
